# 🤖 Telegram Бот Контроля Обходов

Профессиональный бот для Telegram для автоматизации расписания обходов, фиксации выходов дежурных, контроля времени реакции и формирования ежедневных отчетов для руководства.

---

## 🌟 Ключевые возможности

* ⏰ **Автоматическое расписание обходов:**
  * Часовой пояс: `Asia/Tashkent` (`UTC+5`).
  * Рабочие дни: Понедельник — Суббота (`Пн–Сб`).
  * 12 точек контроля в день (утренние и послеобеденные обходы).
* 🔘 **Простое и чистое подтверждение:**
  * Лаконичное напоминание в чате: `🔔 10:00 — Время обхода!`.
  * Кнопка: `[ ✅ Я на обходе ]`.
  * После нажатия сообщение фиксирует факт: `✅ 10:00 — Обход выполнил @username в 10:02`, а кнопка автоматически убирается, сохраняя чат чистым.
* 🚨 **Контроль забывчивости (15 минут):**
  * Если в течение 15 минут никто не подтвердил выход на обход, бот отправляет тревогу в группу и личное уведомление руководству в ЛС.
* 👮‍♂️ **График смен и дежурств:**
  * Назначение дежурных через команду `/duty` или через панель управления.
  * Умное тегирование: бот зовет только тех, кто сегодня на смене.
* 📊 **Ежедневный отчет:**
  * Автоматическая отправка сводки дня в 18:45 в группу и администраторам.
  * Выгрузка по требованию через `/report` или кнопку в меню.
* 📢 **Объявления и Опросы:**
  * Создание форматированных объявлений (с фото и закреплением) и опросов прямо из админ-панели.
* 🎛 **Интерактивная админ-панель:**
  * Управление расписанием (`ВКЛ` / `ВЫКЛ`), списком сотрудников и дежурствами через удобные кнопки.

## 🚀 Установка и запуск

### 1. Клонирование репозитория
```bash
git clone <URL_РЕПОЗИТОРИЯ>
cd <ИМЯ_ПАПКИ>
```

### 2. Настройка переменных окружения
Создайте файл `.env` на основе шаблона `.env.example`:
```bash
cp .env.example .env
```
Укажите ваш токен бота:
```env
BOT_TOKEN=1234567890:ABCdefGHIjklMNOpqrsTUVwxyz
```

### 3. Установка зависимостей и запуск

#### На Windows:
Просто запустите файл:
```cmd
run.bat
```

#### Вручную через терминал:
```bash
python -m venv .venv
source .venv/bin/activate  # На Windows: .venv\Scripts\activate
pip install -r requirements.txt
python bot.py
```

#### Через Docker:
```bash
docker build -t telegram-obhod-bot .
docker run -d --restart=always --name obhod-bot telegram-obhod-bot
```

## 💬 Команды бота

### В личных сообщениях:
* `/start` — Запуск и открытие меню быстрого доступа
* `/admin` — Открытие интерактивной панели управления
* `/report` — Показать итоговый отчет за сегодня
* `/duty` — Проверить, кто дежурит на смене

### В рабочей группе:
* `/setchat` — Привязать текущую группу к боту
* `/duty` — Посмотреть дежурных или заступить на смену
* `/report` — Отчет по обходам за текущий день
* `/status` — Проверить статус системы и точное время
* `/test` — Отправить тестовый вызов на обход
